# ProjectorWarp

굴곡진 벽면·기둥·아치 구조물에 프로젝터를 투사할 때, 원본 화면을 실시간으로 **역왜곡(warping)** 시켜
실제 벽면에서 직선이 직선으로 보이도록 맞추는 Windows 데스크톱 유틸리티입니다.

> **이 저장소는 배포(릴리스) 전용입니다.** 소스는 비공개 저장소에서 관리하며,
> 이곳에는 실행 파일만 올립니다. 앱의 자동 업데이트가 이 저장소의 최신 릴리스를 확인합니다.

## 설치

[Releases](../../releases/latest) 에서 `ProjectorWarp.exe` 하나만 내려받아 실행하면 됩니다.
.NET 설치가 필요 없는 self-contained x64 단일 실행 파일입니다.

| 항목 | 값 |
|---|---|
| OS | Windows 10 1903(빌드 18362) 이상 · Windows 11 권장 |
| 그래픽 | Direct3D 11 지원 GPU (실패 시 WARP 소프트웨어 렌더러로 폴백) |

## 자동 업데이트

앱의 **[9. 버전 · 업데이트]** 에서 새 버전을 확인하고 그 자리에서 설치할 수 있습니다.
확인만 하고 알려주며, **[설치 후 재시작]** 을 누르지 않으면 아무것도 바뀌지 않습니다.
설정할 것은 없습니다.

## 주요 기능

- **내장 재생** — 동영상과 PPT·PDF·이미지 슬라이드를 앱이 직접 재생합니다(외부 플레이어 불필요).
- **화면 캡처** — 실행 중인 창을 `Windows.Graphics.Capture` 로 캡처합니다.
- **기하 보정** — 코너 핀/키스톤 → 베지어 곡면(3×3~6×6) → 다각형 마스킹.
- **색상 보정 · 엣지 블렌딩** — 멀티 프로젝터 구성 지원.
- **프리셋 · 자동 시작** — 보정값을 저장하고, 로그온 시 자동으로 투사를 시작할 수 있습니다.
